05异常路径设计

四种异常各有用户可读的出路，全部不崩溃、不留损坏文件。

场景行为
断网30s 超时 → 提示保留断点；重试自动先主源后镜像各一次；206 响应才续传，200 则全量重下
磁盘不足下载前 GetDiskFreeSpaceExW 预检（需求 + 64MB 余量）→ 明确报错，不落半截文件
校验失败sha256 不符 → 删除 .part → 台账记 download_failed/sha256_mismatch → 重试即全新下载
删除/损坏权重引导页「删除已下载权重」按钮释放空间并记账；旧文件校验不符自动引导重下，不误用
sidecar 被杀看护线程捕获退出码 → 原生对话框「重启服务 / 退出应用」→ 重启后自动刷新窗口
