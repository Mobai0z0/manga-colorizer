## 2. 一致性契约 (跨图统一规则)

1. **色相是硬契约**: 同一角色任何部位的色相 (YUV phi 角) 与色板偏差 ≤ **8°**;
2. **亮度随线稿走**: 引擎保留原稿亮度,因此夜间/暗光场景允许明度与饱和度变化
   (如暗光下 `#F1C27D → #E3B676`),色相不变即视为同一角色;
3. **颜色只从色板来**: 上色提示点一律由 `colorize-palette` 从色板 JSON 生成,
   禁止手填 RGB,从源头杜绝"两张图随手取色不一致";
4. **肤色双重校验**: 色板自检 (入口拒绝非自然肤色) + 成图取样复检 (5×5 中值)。

## 3. 边界情形处理规则 (均有场景示例验证)

| 情形 | 规则 | 验证示例 |
|---|---|---|
| 多人同框 | 每个角色独立色板+独立槽位;两位角色的提示点按"亮度距离+空间距离"归属各自区域,互不污染 | `akari-duo.png` (明里/莲 8 提示点,双向校验 PASS) |
| 夜间/暗光 | 场景灰度整体 ×0.8,色板不变;成图亮度随线稿变暗,色相偏差 ≤8° 即 PASS | `akari-single-dim.png` (色相偏差 0°–1°) |
| 遮挡区域 | 被遮挡部位无需取样点 (校验只对可见槽位);解除遮挡的新图沿用同一色板即可自动一致 | 色板契约 §2.1 |
| 非人部位 | 服装/道具/背景走色板 `uniform`/`scarf` 等自定义 role;纸白/墨线由引擎锁定为无色 | 三张成图的纸面/速度线均为 0 饱和度 |

## 4. 肤色常识清单 (验收用)

- [x] 肤色色相落在自然扇区 (由种子色五档推导,含 4° 余量) — 引擎入口+成图双重强制
- [x] 不发绿: 绿象限色相会被旋转回最近扇区边界 (`enforceNaturalSkin`)
- [x] 不发灰: 肤色色度幅值下限 0.05,低于则提升
- [x] 不蜡像: 幅值上限 0.5 (过饱和同样被压回)
- [x] 不同人种可区分: 明里 IV 档 vs 莲 III 档,双人图对比明确
- [x] 嘴唇/腮红/阴影: 随亮度保留自然过渡 (阴影=同色相低亮度,不偏紫不偏灰)
